🛒 Online Grocery Shopping Management System

A responsive frontend-based online grocery shopping website developed using HTML, CSS, and JavaScript.

📌 Project Overview

This project is a frontend e-commerce application that simulates an online grocery shopping experience. Users can browse grocery products, search for products, manage their shopping cart, proceed through checkout, and view order information through a user-friendly interface.

✨ Features

- 🏠 Home page
- 🛍️ Product browsing
- 📂 Product categories
- 🔎 Product search
- 🛒 Add to cart
- ➕ Increase or decrease product quantity
- ❌ Remove products from cart
- 💰 Automatic cart total calculation
- 💳 Checkout interface
- 📦 Order placement interface
- 📋 Order history
- 👨‍💼 Frontend admin product management
- 📱 Responsive design
- 🎨 Modern and user-friendly interface

🧑‍💻 Technologies Used

- HTML5 – Structure of the website
- CSS3 – Styling, layout, and responsive design
- JavaScript – Product management, search, cart operations, and interactive features

🛒 Main Modules

Customer Module

- Browse grocery products
- Search products
- Filter products by category
- Add products to cart
- Update product quantity
- Remove products from cart
- View total amount
- Proceed to checkout
- View order history


Admin Module

- Frontend admin interface
- Add new products
- Display products dynamically using JavaScript

«Note: This project is currently frontend-only. Admin functionality is implemented on the client side and does not use a backend database.»

📱 Responsive Design

The website is designed to provide a user-friendly experience on:

- Desktop
- Laptop
- Tablet
- Mobile devices

🎯 Project Objective

The objective of this project is to develop a practical frontend e-commerce application and demonstrate skills in HTML, CSS, JavaScript, responsive web design, DOM manipulation, and client-side functionality.
